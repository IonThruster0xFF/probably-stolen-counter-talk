Counter Talk / 柜台闲谈 0.3.11（实验版）

下载 CounterTalk-0.3.11-public.zip，解压后将 CounterTalk 文件夹放入游戏根目录的 Mods 文件夹。
在原版模组管理中审核启用、按提示重启，并在齿轮设置中填写自己的 API URL、模型名和 API-key。
默认 DeepSeek；F6 打开对话，Enter 发送，Alt+Enter 换行。

功能：普通NPC对话、整组议价、有限预算调整、真实成交上下文、公开身份/物品标签和新闻背景、历史报价比较。
剧情及通缉等受保护角色不开放。模型输出可能有误；最终交易须在原版界面完成。

本版本大量采用AI辅助制作，缺乏充分、系统的人工代码review，未经独立安全审计。
