[h1]柜台闲谈 / Counter Talk[/h1]
让《深空当铺》的普通顾客真正和你聊起来。

按 F6 输入你想说的话，与顾客聊天、打听他们愿意透露的背景、讨价还价。NPC 的回复使用原版气泡；谈妥的价格会落在原版物品价格明细里，最终仍由玩家通过原版交易界面结算。

[h2]主要功能[/h2]
[list]
[*]结合原版对白、公开身份、物品标签与液量、所有权、声望和实时预算进行对话。
[*]支持整组物品议价，并根据数量、单价、之前的报价和需求紧迫性考虑交易。
[*]顾客可在限额内调整预算，拒绝不合适的条件，或在谈崩后离店。
[*]已完成的买卖进入上下文，公开新闻作为可选背景，不强制每次评论。
[*]根据游戏语言回复。每位来访顾客的聊天独立；暂不支持跨游戏重启的长期记忆。
[/list]
剧情、通缉及受保护特殊角色不开放 AI 会话。模型仍可能误解或说错话，代码校验也不能保证覆盖全部边缘场景。

[h2]安装与使用[/h2]
订阅并下载后，在游戏原版模组管理中审核启用，按提示重启。点击模组旁的齿轮填写 API URL、模型名称和自己的 API-key。
默认使用 DeepSeek；支持兼容当前 Chat Completions/JSON 请求格式的 HTTPS 服务，其他供应商尚未全面验证。
F6 打开输入框，Enter 发送，Alt+Enter 换行。请先用测试存档体验；不要同时启用多个同 ID 的本地/工坊副本。

[h2]API、费用与数据[/h2]
公开版本不附带 API-key，也不提供免费模型额度。调用费用由你的 API 账户承担。
使用 AI 对话时，输入、对话上下文、顾客与物品状态及公开新闻等必要数据会发送到你配置的模型服务。Key 输入框遮罩，但游戏会在本机明文保存配置，请勿公开配置文件。
模组声明 network 和 reflection-external 能力。交易、预算及声望会影响游戏进度；停用模组不会撤销已经完成的交易。
