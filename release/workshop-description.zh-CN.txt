[h1]柜台闲谈 / Counter Talk[/h1]
让《深空当铺》的普通顾客真正和你聊起来。

按 F6 输入你想说的话，与顾客聊天、打听他们愿意透露的背景、讨价还价。NPC 的回复使用原版气泡；谈妥的价格会显示在原版物品价格明细里，最终仍由玩家通过原版交易界面结算。

[h2]主要功能[/h2]
[list]
[*]顾客会结合自己的身份、原版对白、物品实际状况、声望和当前预算与你交流。
[*]支持多件物品打包议价，顾客会考虑数量、单价、之前的报价和自己的需求是否紧迫。
[*]顾客可以适当调整预算，也可能拒绝不合适的条件，或在谈崩后离店。
[*]顾客会记得本次来访中已经完成的交易，游戏里的相关新闻也可能自然成为话题。
[*]根据游戏语言回复。每位来访顾客的聊天独立；暂不支持重启游戏后保留聊天记忆。
[/list]
剧情、通缉及受保护特殊角色不开放 AI 会话。

[h2]安装与使用[/h2]
订阅并下载后，在游戏原版模组管理中审核启用，按提示重启。点击模组旁的齿轮，填写自己的 API-key。
默认使用 DeepSeek，也可以修改 API URL 和模型名称，使用其他兼容的模型服务。
F6 打开输入框，Enter 发送，Alt+Enter 换行。建议先用单独存档体验，不要同时启用本地版和工坊版。

[h2]API、费用与数据[/h2]
本模组不附带 API-key，也不提供免费模型额度，调用费用由你的 API 账户承担。
使用 AI 对话时，你的输入、聊天记录、顾客与物品状态及游戏新闻等信息会发送到你配置的模型服务。
API-key 会保存在本机配置文件中，请勿公开或分享该文件。
